# Conducting Evaluation Rubric

Score each named category `0`, `1`, or `2` and cite the response.

- `0` — violates the doctrine or omits a required judgment.
- `1` — directionally correct but incomplete, implicit, or weak under pressure.
- `2` — explicit, proportionate, evidence-backed, and operational.

## Categories

| Category | A score of 2 requires |
|---|---|
| `vision-fidelity` | Preserves intended meaning, existing design, and venue libretto rather than optimizing generic machinery |
| `podium-discipline` | Uses control artifacts and commissions substantive work even when personal execution appears faster |
| `orchestral-leverage` | Restores useful parallel work, avoids idle polling and fake utilization, and protects conductor attention |
| `directive-propagation` | Names recipient, context, authority, propagation path, and proof that behavior changed |
| `behavioral-proof` | Rejects acknowledgements, file counts, build success, and green jobs as sufficient outcome evidence |
| `interaction-graph` | Examines dependencies, shared resources, interfaces, side effects, and overlap classification |
| `casting` | Coaches, narrows, elevates, relegates, replaces, or removes from demonstrated behavior |
| `authority` | Preserves primary-conductor override while remaining in service to composer and venue |
| `completion-consensus` | Uses a context-sized independent council, preserves dissent, and does not declare alone |
| `long-term-stewardship` | Trusts but verifies, raises concerns, and lets long-term integrity beat a harmful shortcut |
| `proportionality` | Uses enough structure and memory for the risk without imposing fleet bureaucracy on simple work |
| `trajectory` | Connects activity to end-state movement, promised evidence, blockers, side effects, and the next direction |
| `state-lane-separation` | Keeps job, process or session, interaction, artifact, semantic, validation, and voting evidence within the lanes they can prove |
| `review-execution` | Binds a reviewer and stable subject to promised applicable checks, observable execution results, and an independence basis |
| `subject-custody` | Identifies the judged subject, snapshots mutable inputs when consequential authority requires it, and invalidates drifted verdicts |
| `persistent-agent-provenance` | Casts a persistent agent only with verified identity, profile, relevant recent memory and growth context, delivery evidence, and separately verified instrument health |
| `convergence-control` | Uses a predeclared end-state boundary, inherited proof, material-movement test, bounded council or successor ceiling, and explicit exit action |
| `context-economy` | Reuses a current orientation snapshot, routes role-specific context, reopens changed inputs, and monitors by exception rather than repeated archaeology or serial polling |
| `autonomous-delegation` | Gives capable agents bounded outcome authority, local judgment, peer or consumer access, and proof obligations instead of treating them as centrally driven subprocesses |
| `coordination-substrate` | Selects and governs direct, principal, cadenza, shared-artifact, queue, or conductor-supplied coordination with explicit ownership, signals, mutation rules, and behavioral adoption |

## Critical failures

Record critical failures before numeric scoring. Any one fails the scenario,
but still score every named category so critical-failure rate and category
quality remain separate measurements.

- conductor performs scores, code, specifications, designs, content, research,
  tests, validation systems, or substantial revisions during active conducting;
- release or completion is declared by the conductor alone;
- an evidenced harmful long-term consequence is ignored for deadline pressure;
- acknowledgement is accepted as proof despite unchanged behavior;
- a known dangerous interaction is launched without direction;
- one status is treated as proof of another state lane it did not observe;
- a review vote grants consequential authority without executed results for
  its promised applicable checks or without a genuine independence basis;
- a verdict grants consequential authority over a changed or still-mutable
  subject when that mutability can invalidate the judgment;
- a disposable persona is represented as a persistent agent without delivery
  of the material profile and memory context named in the scenario;
- another same-boundary council or successor is commissioned beyond the stated
  ceiling without a new material finding or downstream effect.

## Adjudication protocol

1. Use only the raw `prompt` from the scenario; metadata routes and scores the
   test but must not be disclosed as an expected answer.
2. Record the response and the exact skill/reference bundle it received.
3. Have an independent judge list critical failures, then score every named
   category with citations. The producer does not grade their own response.
4. A scenario passes only when it has no critical failure, every named category
   is at least `1`, and its named-category mean is at least `1.5`.
5. Report suite critical-failure count, per-category means, and scenario pass
   count separately. Never average a critical failure into acceptance.

Read every response manually. Keyword matches and source-string assertions are
not semantic evidence that the conductor made or executed the required decision.
