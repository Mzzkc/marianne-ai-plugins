# Marianne Expert 1.1.0 Package

The plugin repository is the canonical source. Installed Codex and Agents
copies are deployment outputs verified by `MANIFEST.sha256`.

- `SKILL.md`, `BOOTSTRAP.md`, `TASK-MAP.md`: compact routing, current-versus-
  pinned precedence, and task selection.
- `scripts/preflight.py`: capability, authorization, harness, source-state, and
  optional online-primary-source discovery.
- `scripts/release_manifest.py`: relocatable exact-file release verification.
- `playbooks/`, `contracts/`, `templates/`, `examples/`: task guidance and
  practice artifacts.
- `evidence/`: the immutable pinned snapshot layer; never a replacement for
  current source inspection.
- `evals/`, `priming/`: historical factual defenses and failure cues. Acting
  acceptance is recorded separately in `RELEASE.md`.
- `memory-template/`: optional memory schema. It has no implicit destination.
- `agents/openai.yaml`: discovery metadata.

Development publisher scores, season notes, and moved workspace paths are not
runtime package contents.
