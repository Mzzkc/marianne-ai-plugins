# Legacy one-off helpers

The profiles in this directory are legacy plugin helpers for bounded tasks.
They are not templates for Marianne's persistent agent system, are not entries
in the persistent registry, and must not be given counterfeit identity or
memory continuity.

Modern persistent agents are composed from portable seeds, box-local L1-L4
identity/memory, techniques, roles, cadenzas, lifecycle scores, and live-bound
instruments. See `../docs/ref/modern-agents.md` and `../agent-scores/`.
